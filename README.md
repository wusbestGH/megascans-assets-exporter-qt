# What is this
**Megascans Asset Exporter** is a utility to export Megascans assets downloaded from Quixel Bridge. It can to export into Blender and Cinema 4D and other 3D Editors. You can select your path to Megascans Library, App and Port to export asset. You dont need to login to your account and use Fab to export assets, you can even import your assets to quickly.

# How to use
Clone the repository to your computer
```bash
git clone https://github.com/wusbestGH/megascans-assets-exporter-qt
```
or download source code by "Download ZIP"</br>

Then go to repo and run the script
```bash
python3 main.py
```
